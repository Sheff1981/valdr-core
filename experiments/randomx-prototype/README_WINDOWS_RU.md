# VALDR — замер реального CPU на Windows

Это пакет для обязательного этапа **M5 Mainnet calibration**.

Он **не запускает Mainnet**, **не майнит VDR** и ничего не устанавливает в систему.  
Пакет только измеряет производительность RandomX на вашем реальном компьютере.

## Как запустить

1. Распакуйте ZIP в обычную папку.
2. Закройте тяжёлые программы, игры и лишние вкладки браузера.
3. Дважды нажмите:
   `RUN-VALDR-BENCHMARK.cmd`
4. Подтвердите запуск теста.
5. Дождитесь надписи `BENCHMARK FINISHED`.
6. В этой же папке появится:
   `valdr-randomx-real-cpu.txt`
7. Пришлите этот TXT-файл в чат проекта VALDR.

## Что будет измерено

- модель CPU;
- Windows;
- объём памяти;
- число логических процессоров;
- RandomX на 1 потоке;
- 2 потока;
- 4 потока;
- все логические потоки.

## Важно

RandomX может заметно загрузить CPU и память — это нормально для benchmark.

Если окно покажет `BENCHMARK FAILED`, сделайте скриншот ошибки и пришлите его вместе с описанием компьютера.
